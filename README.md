# ClipMate 复制粘贴助手

Windows 上的一个小工具：**剪贴板历史 + 话术库**。

点一条 → **复制到剪贴板** → 你自己按 `Ctrl+V` 粘到任何地方。

它**不做**这些事：不模拟按键、不注册全局热键、不抢焦点、不碰别人的窗口。所以它不会替你「插进 Word」，也不会在你打字时突然弹出来。

> **作者本人已不再使用这个工具**，仓库留作参考。下面如实写清它的问题，看完再决定要不要用。

---

## 它能干什么

- **剪贴板历史**：后台记录你复制过的纯文本，最新在最上面；能搜、能置顶、能清空
- **话术库**：预先存几段常用文字，用到时点一下复制走
- 数据全部存在程序目录的 `data\` 下，不上传、不联网、不需要账号

## 已知问题（照实说）

1. **可能让 Word 卡一下**：剪贴板每 **120ms** 轮询一次。Windows 的剪贴板同一时刻只允许一个程序访问，你在 Word 里复制大段带格式的内容时，两边会撞上，表现是"点了复制没反应"或短暂卡顿。想改的话，把 `clipwatch.py` 里的 `interval=0.12` 调大即可。
2. **不过滤密码**：任何程序复制到剪贴板的文字都会被**明文**写进 `data\history.json`。它不上传、不加密。如果你会复制密码，请自行决定要不要用。
3. **只收纯文本**：图片、文件、带格式的富文本都不记。
4. 最多 200 条、单条 20000 字；内容完全相同的只留一条并提到最前。
5. 它自己不重复记录（自己写进剪贴板的内容不会再被采集）。

## 怎么跑

需要 Python 3.12（只用标准库，没有第三方依赖）：

```bat
pythonw app.pyw
```

打包成单文件 exe（可选）：

```bat
pip install pyinstaller
pyinstaller --noconsole --onefile --icon app.ico --name ClipMate app.pyw
```

注意：打包后 `data\` 会建在 **exe 同目录**（`paths.py` 里对 frozen 状态做了处理）。只拷走 exe 而不同时带上 `app.ico` 的话，窗口图标会变白板，功能不受影响。

## 目录结构

```
clipmate/
  main.py        入口，起窗口 + 起后台采集
  ui.py          tkinter 界面（标签页：剪贴板历史 / 话术库）
  store.py       历史与话术的读写、去重、上限淘汰、置顶
  clipwatch.py   剪贴板轮询（120ms）
  clipboard.py   剪贴板读写封装
  win32.py       ctypes 声明（窗口、消息）
  shell.py       无边框窗口的外壳行为
  paths.py       数据目录解析（含 frozen 分支）
  icon.py        图标生成/加载
app.pyw          启动脚本
app.ico          图标
```
